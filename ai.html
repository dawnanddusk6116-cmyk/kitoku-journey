01 / PHILOSOPHY
自分専用のAIを育てる
第2の脳としてAIを育てる、という使い方が広がっています。
その多くは、仕事の効率化や成果を目的にしたものです。

KITOKUがまず提案したいのは、もう一つの使い方。日々の生活の中で、自分自身と向き合うための右腕です。気学は、今日の服、香り、食べるもの、大事な人との距離感を決める時の要素になります。

答えを出してくれるのではなく、選ぶための材料を増やしてくれるものです。KITOKUは、その材料をAIに渡しやすい形に整える場所です。
まずは身近な生活から
ここで育てた右腕は、仕事の場面にもそのまま応用できます。AIに答えを丸投げするのではなく、あなたの判断を助ける右腕として、少しずつ育てていってください。
02 / HOW TO USE
こんな時、こう使う
毎日必ず訪れる場面ほど、AIも育ちやすくなります。
日盤吉方を取りに行く時
気学では、日盤の吉方位へ実際に足を運ぶ「吉方取り」が、最も基本的な実践です。KITOKUは、その方向で何を取り入れるかまで処方します。
「今日の吉方は西（七赤金星）です。金の五行のエネルギーに合わせた、コンビニで買える飲み物や食べ物を3つ提案してください。色はピンク・オレンジ・金が合っています。」
「コピーして使う」を押して、そのままAIに貼るだけです。方位へ向かう道すがら、実際に買うものまで、その場で具体的に決まります。
体調管理アシスタントを育てる
体重計・体組成計のデータに今日の五行を添えると、数字の変化を体調の流れとして読み解いてくれるようになります。
「体重が昨日より1.3kg増えました。骨格筋量と体内水分率も上がっています。これは何が起きていると考えられますか？ 気学では今日は土のエネルギーの日です。」
これは脱水からのリカバリーとして、体が正しく機能した証拠です。筋肉にグリコーゲンと水分が引き込まれたための増加で、体脂肪が増えたわけではありません。
細かい読み解きをAIに任せ、自分は大きな流れだけ見ていられることが、育てる価値のわかりやすい実感になります。
ワードローブアシスタントを育てる
手持ちの服を写真に撮って相談する時、自分の九星や今日の処方色を一緒に伝えると、選択肢の理由づけが深くなります。
「私の本命星は六白金星、月命は一白水星です。手持ちの服は黒が多いのですが、紺と黒、自分にはどちらが合っていますか？」
紺は、水のエネルギーを活性化させるシンボルカラー。黒は、深みと重厚感を出す相棒カラー。日常は紺を主役に、引き締めたい日は黒を使い分ける、という考え方ができます。
「どちらが正解か」ではなく、それぞれがどんな役割を持つ色かを教えてもらえるのが、育てる価値です。
②で気になった例は、下の図で確認できます。「今日を整えたい」「人に合わせたい」「自分を深掘りしたい」「育てていきたい」のどこに対応するか、確認してみてください。

04 / EXPAND
慣れてきたら、広げられる場面

体調管理・服選びに慣れてきたら、他の場面にも同じやり方を応用できます。

手持ちの香水を、自分の九星で分析する今持っている香水を写真や名前で伝え、「自分の本命星に合っているか」「足りない五行を補うにはどれが良いか」を相談します。
好きな香水サイトのURLを貼る「セレス」「Coén」のような少量から試せる香水サイトのURLを添えると、実在する・今買える商品の中から選びやすくなります。
香りAI先生に進む「手持ち香水を使い分ける」「自分の香りを選ぶ」「会う人に合わせる」「贈り物・救済モード」へ、そのまま考え方を広げられます。
仕事や人間関係にも使う商談で相手に安心感を与える香り、好きな人との距離の詰め方なども、「実際のデータ＋今日の気学情報」で相談できます。
05 / FOUR BRANCHES
日・人・深・育の詳細
今日を整える、人に合わせる、自分を深掘りする、もっと育てる。上のAI USE TREEの4つの枝が、KITOKUでAIに渡せる材料の全体像です。
06 / GROW
育て方の3段階
一気に全部を使いこなす必要はありません。今の自分に合う段階から、少しずつ進めてください。
初級：まず1つのチャットに貼る本命星・月命星・傾斜・同会・納音などの基本情報は最初の1回だけ。今日の方位盤・処方色・香りは日によって変わるので、その日の分を都度貼ります。
中級：テーマごとにチャットを分ける仕事用・人間関係用・体調や美容用、と分けると、AIが混乱せず、より的確な答えを返しやすくなります。
上級：知恵の蔵として育てるNotebookLMやObsidianなどに、相談の記録や気づきを少しずつ蓄積していく方法です。慣れてきたら試してみてください。
07 / FIRST STEP
はじめの一歩
基本情報をコピーするあなたの基本情報（本命星・月命星・傾斜・同会・納音）をコピーして、いつも使っているAIチャットに貼ってください。
最初の一言を添える「これは私の気学の基本データです。今日から、私の日常のアドバイザーとして相談に乗ってください。」
今日困っていることを聞くあとは、今日困っていることを、そのまま聞いてみてください。
08 / MEMORY
もっと手間を減らしたい方へ

同じチャットを固定して使う方法だけでも、日々の相談には十分です。ただ、テーマごとにチャットを分けると、新しいチャットを開くたびに基本情報を貼り直す必要が出てきます。

これを避けたい場合、多くのAIには基本情報を一度登録すれば、どのチャットを新しく開いても、最初から覚えていてくれる設定があります。

ChatGPT設定 → パーソナライズ → メモリ
Gemini設定 → パーソナルインテリジェンス → カスタム指示

ここに基本情報を一度だけ登録しておくと、その日の方位盤や処方だけを貼れば準備完了です。設定名は変わる場合がありますが、テーマ別にチャットを分けたい時に便利です。

① あなたの星情報（自動生成）
生年月日を登録すると自動で表示されます
まずはこの星情報を、いつものAIチャットに貼ってください。同じチャット内では、あなたの基本情報として相談の土台になります。
② 相手の星も入れる（この画面だけ）
商談相手・家族・上司・パートナーなどの生年月日を入れると、相手の星情報を一時的に相談材料へ加えられます。相手に合わせた言葉・色・香り・距離感を相談したい時に使ってください。保存はしません。
相手の生年月日を入れると、ここに星情報が表示されます。
⚠ AIの回答はあくまで参考です。最終的な判断はご自身でお願いします。
服や持ち物の写真は相談に役立ちますが、住所・金融情報・職場の機密・相手の個人情報などは、必要がない限りAIに渡さないようにしてください。
